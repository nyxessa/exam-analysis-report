# 试卷分析报告（Excel 收表 → 逐人点评 → 两页报告 → 质检）

> 一次考试给每个学生出一份 A4 分析报告，另加一页班级卷面分析。
> **老师只需要填一份 Excel**：不起服务、不装软件、不联网；PDF 由系统 Edge 打印。

**许可**：PolyForm Noncommercial 1.0.0 + 教育使用补充授权——教师与学校可免费使用；
闭源商业软件集成、收费 SaaS / 商业 API 需另行授权。全文见 `LICENSE.md`，再分发时随包保留。

## 安装（接收方第一次用，照着做）

**依赖**：Python 3.9+（只用标准库，不装任何包）+ Edge 或 Chrome（打 PDF 用）。不需要网络。

**装法**（任选一种，装完都要**重开一个对话**才会加载）：

| 方式 | 做法 |
|---|---|
| 上传（最省事） | 技能面板 →「添加技能」→「上传技能」→ 把这个 zip 拖进去 → 确认安全弹窗 |
| 解压放目录 | 解压后确认路径是 `~/.workbuddy/skills/exam-analysis-report/SKILL.md`，**别把 SKILL.md 直接摊在 skills/ 下** |
| 项目级 | 放进 `<工作区>/.workbuddy/skills/`，随仓库共享给同事 |

**装完先验两条命令**（都在 skill 根目录跑）：

```bash
python scripts/selftest.py      # ① 环境自检，五项全过
python scripts/demo.py          # ② 用 3 个虚构学生跑通全链路，结束时打印 PDF 在哪
```

`demo.py` 能出 3 份 PDF 就说明这条链路在你机器上是通的，可以接真数据了。
出不来不要硬跑真数据，按 `references/troubleshooting.md` 排。

## 何时用 / 不用

**用**：老师说「做这次试卷分析」「出学情报告」「统测报告」「期中分析」「给全班出报告」，或直接扔来一份填好的成绩表加卷子。

**不用**：单题讲解、组卷出卷、只要一张成绩排名表（不需要报告）。

## 这个包的范围

只含**主流程**：Excel 收表 → 证据包 → 逐人点评 → 两页报告 + 卷面分析 → 质检。

不含旧网页标注器、旧 xlsm / 细目表导入。遇到这类输入就让老师把题目信息整理进模板，
不要在本包里找对应脚本——它不存在。

## 你要做的只有四件事

| 你做（花额度） | 脚本做（零额度） |
|---|---|
| ① 读原卷，核对题型/分值/知识点（可选，没原卷也能跑） | ② 收表、校验、算统计、画图、排版、打 PDF、打包 |
| ③ 写全班点评（一次调用写完，不许逐个推理） | ④ 生成证据包、台账、卷面分析、质检 |
| ⑤ 把质检结果翻成人话讲给老师 | |

**绝对不要**：逐个学生推理、逐个改 PDF、手抄分数、自己算平均分。

## 五步流程

工作目录约定：**一次考试一个文件夹**。

运行环境（已随包满足，不要装东西）：

- Python 3.9+，只用标准库（Excel 读写走自带的 `xlsxlite`，不需要 openpyxl）。
  下文简写 `python`；不在 PATH 上时按这个顺序找，**别照抄某个具体版本号**（每台机器不同）：
  ① `python3` 或 `py -3`；② `<用户目录>/.workbuddy/binaries/python/versions/*/python.exe`
  里任意一个能跑 3.9+ 的（版本号目录自己看）；③ 都找不到就问用户装 Python，不要自己下载。
- 路径一律写 `C:/...` 正斜杠原生路径，不写 `~` 或 `/c/...`；
- PDF 由 Edge/Chrome 无头打印，找不到时用环境变量 `EDGE_PATH` 指定；
- **第一次运行先自检**：`python scripts/selftest.py`（五项全过；加 `--pdf` 变六项，连打印链路一起验）。
  再跑 `python scripts/demo.py` 用示例数据走一遍全链路，确认能出 PDF。
  给人类看的安装说明在 `README.md`。

```
期末-八年级物理/
├── 01_试卷/                原卷（可选：PDF / 照片 / Word）
├── paper.json              ① 收表产出：考试信息 + 题目结构（含三级备注）
├── 录分结果.json            ② 收表产出：学生逐题得分
├── panels.json             ③ 你写：逐人个人点评

│   ├── 点评证据包.json      ④ 脚本产出：写点评的唯一事实来源
│   ├── 001_姓名.pdf/.html  每人 1–3 页（题多续页）
│   ├── 卷面分析.pdf         教师版一页
│   ├── 渲染信息.json        每份应有几页（质检拿它核）
```

### 第 0 步 · 把模板交给老师

模板在 skill 里：`assets/试卷分析模板.xlsx`。两个 Sheet：

- **试卷信息**：考试名称/日期/校区/年级/班级/科目/授课教师/卷面满分/考试备注 + 逐题 10 列
  （题号、题型、本题分值、对应模块、具体知识点、常见错因、复习页码、具体复习题号、后续学习建议、题目备注）；
- **学生成绩**：学号、姓名、缺考、第1题…第N题、学生备注。

不要自己现做一个模板。题数不够时再生成一份更宽的：

```bash
python scripts/make_template.py --questions 30 --students 80 --out "<路径>/试卷分析模板.xlsx"
```

### 第 1 步 · 收表（校验到单元格）

**先看表是不是我们的模板**（老师十次有八次会用自己的旧表）：

| 情况 | 怎么办 |
|---|---|
| 两个 Sheet 名是「试卷信息 / 学生成绩」，表头能对上 | 直接收表 |
| Sheet 名不同、或列名不同 | 让他照 `assets/试卷分析模板.xlsx` 抄一遍表头，或把数据粘进新模板；脚本按表头**文字**认列，列序可变，列名不可变 |
| 只有一张分数表、没有逐题信息 | 逐题分值/知识点必须补，否则出不了结构表和明细；先和老师确认能不能补 |
| 是旧 xlsm / 细目表 | 本包**不含**旧表导入，让老师把题目信息整理进模板；这是机构内部旧格式，对外无意义 |
| 是 `.xls` | 让老师另存为 `.xlsx` |

老师把填好的 Excel 交回来（可同时给原卷）：

```bash
python scripts/ingest_excel.py --xlsx "<老师给的.xlsx>" --out "<考试文件夹>" \
       --paper "<原卷.pdf>"          # 原卷可省略
```

它会拦住并指到单元格：题号重复、分值和≠卷面满分、得分超满分、学号重复、分值非数字、缺题号。
**有错就把报错原样转述给老师，不要自己改数字往下跑。**

**机构 Logo 与主题色（可选）**：默认主题色是蓝紫 `#3F3B92`，报告顶部不放 Logo。
老师给了校徽，就一起传进来——报告页眉用 Logo，标题、分数、图表、表格线全部换成 Logo 的主色：

```bash
# 收表时一起设
python scripts/ingest_excel.py --xlsx "…" --out "<考试文件夹>" --logo "校徽.png"
python scripts/ingest_excel.py --xlsx "…" --out "<考试文件夹>" --theme "#C8102E"   # 或手动指定

# 已经收过表，只想换 Logo / 换颜色：改 paper.json 里的 brand，不用重新收表
python scripts/brand.py --exam-dir "<考试文件夹>" --logo "校徽.png"    # 自动取色
python scripts/brand.py --exam-dir "<考试文件夹>" --theme "#1F6F5C"    # 手动指定
python scripts/brand.py --exam-dir "<考试文件夹>" --clear              # 去掉 Logo，回默认蓝
python scripts/brand.py --show --exam-dir "<考试文件夹>"               # 看当前用的是哪套
```

- 取色直读 SVG / PNG；JPG 会先调系统工具转一次 PNG，转不了就提示改用 `--theme` 手动指定。
- 自动取到的主色会按白纸印刷可读性校正（压深到对比度够用），不会照搬 Logo 里的浅色。
- 机构色接近「失分红」时，图表里的达标柱会自动压深一档，和红色失分标记区分开。
- Logo 建议透明背景 PNG、横版；显示框 196×40px，等比缩放，不拉伸不裁切。
- 改完 **重跑 `build_reports.py` 就生效**，已经收好的数据不用动。

`paper.json` 的字段含义与建卷归一规则见 `references/paper-schema.md`；
同一个错换着输入反复出现，去 `references/troubleshooting.md` 对号入座，别现场造解法。

**可以留空的字段**（留空＝不显示，不是取默认值，更不能把右边那个标签当成自己的值）：

| Sheet | 可空 | 空了的后果 |
|---|---|---|
| 试卷信息 | 考试名称、考试日期、校区 | 报告页眉只剩「试卷分析报告」，姓名下少一两项 |
| 试卷信息 | 题型、常见错因、复习页码、复习题号、后续学习建议、题目备注 | 明细表对应格显示「—」 |
| 学生成绩 | 各题得分、学生备注 | 空＝未录（≠0 分）；质检会提示「有人题分未录全」 |

必填只有：年级、班级、科目、卷面满分、题号、本题分值、对应模块、具体知识点、学号、姓名、缺考。

> 真实坑：八年级这份卷子页眉印「满分 100」，逐题分值和只有 84。收表会直接报
> 「题目分值合计 84 ≠ 卷面满分 100」，必须先让老师确认按哪个走，不能静默改成一致。

### 第 3 步 · 写点评（唯一需要动笔的地方）

> **场景与角色**：这段话印在学生报告第 1 页最显眼的位置，直接面向**学生本人与身旁的家长**。
> 你是经验丰富、认真负责、懂孩子心理的任课老师，在与他们真诚面对面交底。

读 `references/comment-prompt.md` 的规范 + `reports/点评证据包.json`（或精简的 `reports/评语待写.json`），写 `panels.json`：

```json
{ "students": { "001": { "comment": "一段话，120–180 字，最长 200" } } }
```

#### 【关键流程约束：防上下文污染（强烈推荐子智能体）】
- **为什么需要干净上下文**：主对话执行收表、统计和日志输出后，上下文已堆积大量技术输出和表格代码。在此嘈杂上下文中直接写点评，极易发生**上下文污染**，导致模型下意识模仿冰冷的技术日志体或格式化说明书。
- **操作方式**：派生一个独立的子智能体（subagent）或开启干净上下文，仅向其输入 `references/comment-prompt.md` 与精简的学情数据（如 `reports/评语待写.json` 及该生备注），在纯净的师生沟通语境下专注撰写。
- **分批生成机制**：全班人数较多（如超过 15 人）时，建议按 6–8 人一组分批输出，保证后半段不疲倦、不陷入机械套路。

#### 核心写作原则（讲人话、有温度）：
- **真诚对话，自带温度**：使用自然的师生沟通口吻（“你在本次测试中……”、“从卷面上看，孩子在……”、“建议接下来咱们……”）。亲切坚定，像在办公室促膝长谈。
- **先立足闪光点与基本盘**：无论考多少分，先肯定其优势模块、扎实的基础或端正的卷面态度。**严禁阴阳怪气或打击自尊**（坚决不写“有些还记得/没完全丢/几乎没拿到分/说明公式是用得上的/说明考试状态还在”等冷漠刺耳语言！）。
- **重在思维逻辑与学习方法，拒做实验说明书**：提题号最多 2 个，重点诊断思维漏洞与复习策略，**坚决不在评语里机械复读实验操作规程或背诵题目答案**（不写“重做第28题：把每次调回同一个电压写在表格最上面，记录时只填两列……”）。
- **给落地抓手与真诚期许**：给出一个切实可行的复习抓手（回归课本核心例题/整理错题讲清逻辑/圈画已知量），结尾自然给予温暖笃定的鼓励。

#### 硬规矩（`verify.py` 会逐条查）：
- 一个自然段，120–180 字，硬上限 200 字；不复读总分、不写排名、不横向拉踩；
- 点名的题号**最多 2 个**，其余归到模块或错因类别；
- 成绩数字尽量少用；若用，必须严格在「数字白名单」里（白名单不是训练量来源，不能从中凑训练天数、次数或预计提分）；
- 禁用词：以 `scripts/evidence.py` 的 `BANNED` 为准（含戒骄戒躁、百尺竿头、粗心大意、马虎、基础不牢、多做题、查漏补缺等）；
- 题目备注/学生备注是写作证据，不得原样搬入（隐私、家庭信息、人格评价一律不许，不得连续 8 字直抄）；
- 只有整题得分时，不推断具体小问或步骤，不虚构草稿涂改等作答细节；原卷是题目不是学生答卷；
- 相邻两份开篇前 6 字不得相同；因材施教自然切入。

写完务必对照 `comment-prompt.md` 第六节自读三问：像不像老师面对面谈心？是方法指导还是念答案步骤？学生家长读完心里舒服有底气吗？`verify.py` 查不出文风冷暖，不能用它代替自检。

### 第 4 步 · 出正式报告

```bash
python scripts/build_reports.py --exam-dir "<考试文件夹>"
python scripts/build_class_panel.py --exam-dir "<考试文件夹>"     # 教师版一页，可选
python scripts/verify.py --exam-dir "<考试文件夹>"
```

`verify.py` **必须全绿**才算交付。14 项：

| 层 | 检查 |
|---|---|
| 数据 | ① 分值合计 ② 个人合计 ③ 班均≤满分 ④ 每人有分 ⑤ 缺题（提示） |
| 版面 | ⑥ PDF 数量与页数（对 `渲染信息.json` 逐份核，防溢页被裁） |
| 文字 | ⑦ 数字清单 ⑧ 字数 ⑨ 禁用词 ⑩ 总分/排名复读 ⑪ 题号≤2 ⑫ 相邻开篇重复 ⑬ 数字来源 ⑭ 备注直抄 |

质检不过就按报错改 `panels.json` 重写那几句，**不要手改报告 HTML**。
同一条不过最多重写 **3 轮**；3 轮仍不过，把报错原文交给老师，别为了过关删数字或改口径。

常用开关：`--no-pdf`（只出 HTML 看版式）、`--only 001,002`（先出两份试印）、
`--avg manual`、`--grade quantile`。

### 第 5 步 · 交给老师

> 报告在 `reports/` 里，文件名是 学号_姓名。第 1 页是点评和两张图，第 2 页起是逐题明细。
> `全部报告.zip` 可以直接发（只含学生报告，不含教师版）；`卷面分析.pdf` 是教师版，单独给你，不发家长。
> 要改点评或机构名，说一声，重出一次约 2 秒一份。

老师问「表怎么填」「报告怎么看」，把 `references/teacher-guide.md` 给他——半页纸，可直接打印。

## 口径（错一个就会被家长抓到）

- **难度系数 = 班均 ÷ 满分**；分档 易≥0.75 / 中 0.60–0.74 / 难<0.60。
- **等级 = 得分率**：A≥90% / B≥70% / C≥30% / D≥10% / E<10%（机构旧表校准值，别改）。
  要换口径（比如别的学校用 A≥85），在 `paper.json` 里加 `"grades": {"A":0.85,"B":0.70,"C":0.30,"D":0.10}`
  覆盖，**不要改脚本**——这一处是设计成可配的。
- **成绩段按满分比例划分**，换 120 分卷自动适配。
- **掌握度** ≥80% 掌握 / 60–80% 待巩固 / <60% 薄弱；只对应 1–2 题的不判档，显示「n题」。
- **优势模块**：领先班均 ≥5 个百分点或得分率 ≥85%。
- **缺考**：不计入班均、不出报告，列在班级情况里。
- **题级「常见失分点」不等于该生实际错因**，措辞上必须区分。

## 版面（已定稿，别回退）

- 第 1 页：页眉左侧机构 Logo（**可选，没给就留空**）+ 页眉右侧（**试卷名称，填了才显示** + 「试卷分析报告」）
  → 姓名/年级/班级/科目/授课教师/**校区/考试日期**（有值才显示）/总分/等级 → **唯一一段个人点评**
  → 试卷结构表 + 班级情况表 → 成绩分布直方图（「你在这里」）+ 模块点线图（实心=个人，空心=班均）
  → 居中页码。
- 第 2 页起：只放题目明细（题号 / 得分满分 / 班均 / 知识点 / 常见失分点 / 复习建议）。
- **不放任何小字说明**：等级口径、分段算法、图例解释、复核声明全部不进版面（2026-11 变更）。
  版面里只留数据本身，读者能看懂的规则（红条＝失分题、实心/空心＝个人/班均）靠图形自解释。
- 模块 >4 个时保留分值前 4 个，其余并「其他」，最多 5 行；题号先合并区间（`1–6、8、11`），
  超 26 字符显示「等 N 题」。
- 明细超过一页就续页并动态算页码，**不靠缩字号、不裁文字**。
- 黑白打印要能分清：失分题用底色 + 左侧红线，个人/班均用实心/空心点。

**换机构只换 Logo 和颜色**：本包不含任何机构标识；把对方的 Logo 传进来（或 `--theme` 指定色值），
不要改脚本、不要重绘。没给 Logo 就留空，不报错。

**主题色只改一处**：`paper.json → brand.color`（`scripts/brand.py` 负责写入），模板里用的是 CSS 变量
（`--accent` 系列），新增版面元素要跟着用 `var(--accent)`，不要写死颜色。

## 坑（都踩过）

| 坑 | 现象 | 解法 |
|---|---|---|
| 自闭合标签 | 老师给空单元格刷过格式，xlsx 里出现 `<c r="C1" s="3"/>`，旧正则读取器会吞掉后一格 | 已改用 `xlsxlite`（ElementTree 解析），别再写回正则 |
| MSYS 路径 | `python ~/.workbuddy/x.py` 报 `can't open file 'C:\c\...'` | 传给脚本的路径一律 `C:/...` 开头 |
| 没有第三方库 | 环境里没有 openpyxl / jinja2 / pandas | Excel 用 `xlsxlite`；HTML 用 `@@TOKEN@@` 替换 |
| python 不在 PATH | 直接敲 `python` 找不到或版本不对 | 用绝对路径调，环境决定，不是脚本问题 |
| zip 混入旧报告 | 学生被删/改名后旧 PDF 还在目录里，照样被打进包 | 已修：全量出报告先清残留，zip 只装本轮 `made`；`--only` 不清 |
| 明细页半空 | 题量刚过一页容量时，会分成两张半空页 | 已知取舍：宁可半空也不裁字。真要压到 2 页得调 `DETAIL_BUDGET_MM` 并逐份目检 |
| PDF 靠 Edge | 找不到浏览器 | 用 `msedge --headless=new --print-to-pdf`；可用 `EDGE_PATH` 指定 |
| 页脚叠印 | 每页重复页脚 | 禁用 `position:fixed`，用 flex 列 + `margin-top:auto` |
| 浮点漏出 | 页面显示 `81.10000000000001` | 一律过 `fmt()/fmt_plain()` |
| AI 漂数字 | 写「丢了 7 成」，实际 38% | 证据包白名单 + `verify.py` ⑬ 拦截 |
| Logo 取不到色 | JPG 转不了 PNG，或 Logo 是纯黑白 | `brand.py` 会提示原因；用 `--theme "#RRGGBB"` 手动指定 |
| 机构色是红的 | 图表里「达标柱」和「失分红」分不清 | 已自动把达标柱压深一档；实在分不开就建议老师换个色相 |
| Excel 表头仍是蓝紫 | 模板表头颜色是生成时写死的 | 只影响输入表观感，报告一律按 `brand.color` 出；不用重做模板 |

## 改完怎么验

改环境或改脚本后，按顺序跑这两条，都过再交付：

```bash
python scripts/selftest.py --pdf   # 依赖、素材、Excel 读写闭环、打印链路
python scripts/demo.py             # 示例数据全链路，末尾自动跑 verify
```

版式改动还必须把 PDF 转 PNG 目检（`verify.py` 只看页数，看不出丑不丑）。
