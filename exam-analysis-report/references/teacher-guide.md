# 试用说明（给老师，半页纸）

## 你要做的三件事

**① 填一份 Excel**

用**「试卷分析模板.xlsx」**（两个 Sheet），按表填：

- **试卷信息**：年级、班级、科目、授课教师、卷面满分是**必填**；
  考试名称、考试日期、校区**可以留空**——空着报告就不显示这几项，不会出现空白标签。
  下面逐题填：题号、本题分值、对应模块、具体知识点是**必填**；
  题型、常见错因、复习页码、复习题号、后续学习建议、题目备注都可以空着。
- **学生成绩**：学号、姓名、缺考（下拉选「是/否」）是**必填**；第 1 题…第 N 题的得分、学生备注可空。

留空和填 0 不是一回事：空着＝这题没录，填 0＝这题确实 0 分。

蓝色表头不要改名、不要删列；分数可以整片从别的表格粘贴过来。

**② 把卷子一起给助手（可选）**

PDF、照片、Word 都行。给了原卷，助手会核对题型与分值；没给也能出报告。

**③ 说一声「做好了」**

助手会先校验这张表：分值和对不对、有没有得分超过满分、学号有没有重复，并把问题指到具体单元格。
校验通过后，报告生成在 `reports/` 里：每人一份 PDF（文件名是 `学号_姓名.pdf`），
另有一个 `全部报告.zip` 可以整包发；`卷面分析.pdf` 是给你讲评用的一页。

## 常见问题

| 问题 | 怎么办 |
|---|---|
| 提示「题目分值合计 ≠ 卷面满分」 | 先核对是不是漏填/抄错分值；确认卷子本身如此，就把「卷面满分」改成合计值 |
| 提示「得分超过满分」 | 报错里有单元格坐标（如 `学生成绩!J4`），按位置改那一格 |
| 某个学生缺考 | 「缺考」列选「是」，该生不出报告、不计入班均 |
| 有一两题还没录完 | 留空即可（留空≠0 分）；报告照出，质检会提示「有人题分未录全」 |
| 想加自己的错因说法 | 「常见错因」里直接写，字典里没有的词会当作自由错因文本进报告 |
| 题数超过模板列数 | 告诉我题数，重新生成一份更宽的模板 |
| 报告里机构名/校区是空的 | 告诉助手机构名，改一次全部重出 |
| 只想先看几个学生 | 说「先出前 5 份试印」 |
| 试卷名称/日期/校区没填 | 没关系，这几项本来就是选填，报告会自动省掉 |
| 没有教材页码，复习题号也懒得填 | 只填「后续学习建议」就够，明细里不会留空档 |
| 打印出来是黑白 | 报告设计上不依赖颜色：失分题有底色和左侧红线，个人与班均用实心/空心点区分 |

## 报告怎么看

**第 1 页**

- **个人点评**：一段话，说清这次最值得注意的一处和接下来能直接做的事。
- **试卷结构**：模块、对应题号、分值——先看分值分布，知道这份卷子考了什么。
- **班级情况**：参考人数、班均、最高、最低。
- **班级成绩分布**：柱子上方是人数，紫色的那根就是他所在的分数段，箭头写着「你在这里」。
- **模块得分对比**：实心点是他的得分率，空心点是班均。两点离得越远，说明这一块与班里的差距越大。

**第 2 页起：题目明细**

每题一行：得分/满分、班均、知识点、常见失分点、复习建议。底色和左侧红线表示这题没拿满。
「常见失分点」是这道题常见的错法，不一定是他的实际错因——具体原因要看他卷面。
