# 排障

## PDF / Edge

**报「找不到 Edge/Chrome」**
脚本按顺序找：`EDGE_PATH` 环境变量 → `C:/Program Files (x86)/Microsoft/Edge/Application/msedge.exe`
→ `C:/Program Files/Microsoft/Edge/...` → Chrome 两个常见路径。
都没有就手动指定：

```bash
EDGE_PATH="C:/Program Files/Microsoft/Edge/Application/msedge.exe" python scripts/build_reports.py --exam-dir "..."
```

**PDF 生成了但只有几 KB / 打开是空白**
说明打印时页面还没渲染完。脚本已带 `--virtual-time-budget=3000`；
文件特别大（图片多）时改到 6000。也可能是 HTML 有 JS 语法错误导致整页白屏——见下面「白屏」。

**PDF 页数不是 2 页**
`verify.py` 会直接报出来。原因通常是某段文字变长把第 1 页顶到第 2 页：
模块太多（>6 个）、回补清单超过 3 行、诊断要点超过 5 条。对策是减模块或缩短 `advice` 文案，
不要靠缩字号硬塞（打印出来看不清）。

**打印出来有页眉页脚（URL、日期）**
加 `--no-pdf-header-footer`（脚本默认已带）。

## 数据对不上

| 现象 | 原因 |
|---|---|
| 个人总分 ≠ 各题之和 | 某题录了超过满分的数（界面会标红但依然计入），或 `paper.json` 分值写错 |
| 班均 > 满分 | 同上；`verify.py` ③ 会拦 |
| 模块分值和 ≠ 卷面满分 | `paper.json` 里某题 `full` 写错，或漏了题 |
| 某人的模块全 0 | 该生题分全空（不是缺考），报告里会显示 0 分——先确认是否真缺考 |
| `comments.json` 不生效 | 键用了姓名但录分结果是学号（或反之）。两种键都支持，但名字里有多余空格会不匹配 |

## 中文 / 字体

报告模板用「Microsoft YaHei / 微软雅黑」，Windows 自带。换到没有雅黑的机器（Linux 容器）会掉成默认字体，
字宽变化可能引起折行/溢页——交付前在目标机器上试印一份。

## 路径

- 路径带空格/中文都可以（脚本用 `Path` 处理），但**命令行里要加引号**。
- `--print-to-pdf=` 后面用**原生正斜杠路径**（`C:/xxx/a.pdf`），不要用 `/c/xxx` 或 `/tmp`。
- 生成过程中会建一个临时 Edge 配置目录（`%TEMP%/wb_pdf_*`），脚本结束会删；杀进程中断的话手动清一下。

## Excel 收表

**报「找不到工作表：试卷信息 / 学生成绩」**
老师用的不是 skill 自带的模板（可能删了 Sheet 或改了名）。让他重新下 `assets/试卷分析模板.xlsx` 填一遍，
或者把现有表两个 Sheet 改成这两个名字、表头照模板抄一遍。

**报「题目分值合计 X ≠ 卷面满分 Y」**
先看是不是漏了一题或分值抄错；确认卷子本身只有 X 分，就把「卷面满分」改成 X。
这个检查就是为了拦住原卷页眉与实际分值不一致的情况。

**报「学生成绩!J4：第 7 题得分 9 超过满分 3」**
坐标是「Sheet!列行」。按位置改那一格；`J4` 表示学生成绩表 J 列第 4 行。

**报「未识别的表头」**
只是提示：脚本按关键字认列（「题号」「分值」「模块」「知识点」「错因」「页码」「建议」「备注」），
认不出的列会被忽略，不影响出报告；但如果是被改了名的关键列，会另报「缺列」。

**老师用 WPS 另存后读不出来**
`xlsxlite` 用 ElementTree 解析，兼容 Excel/WPS 的常规保存结果（含 sharedStrings、inlineStr、
自闭合空单元格、日期序列号）。若真遇到解析异常，让老师用 Excel 另存一次 `.xlsx` 再试。

**`.xls` 老格式**
不支持，先用 Excel/WPS 另存为 `.xlsx`（脚本会提示）。

## 出报告

**改了模板/重出了，PDF 看起来还是旧的**
PDF 正被阅读器或预览窗口打开时，Edge 写不进去会静默失败，留下上一版文件。
现在 `print_pdf` 会先删旧文件：删不掉就直接报「正被其他程序占用」，关掉预览再跑。

**试卷名称/考试日期/校区填了，报告里没有**
先看 `paper.json` 的 `exam.title_given` / `date` / `campus` 是否为空。都为空且表里确实填了，
多半是元信息区被挪过位置：值必须写在标签**紧邻的右一格**（模板是 B/D/E/G/I 列），
中间插入空列会读不到。旧版本还有一个 bug——留空时会把右边的标签当成值
（校区空 → 考试日期读成「校区」），已在 `read_meta` 修掉，回归样本 3 覆盖。
