# paper.json 字段与建卷归一规则

一份卷子一个 `paper.json`，**跨班复用**（换班只换录分结果，不动这个文件）。

## 最小可用结构

```json
{
  "exam": {
    "title": "期中统测分析报告",     // 报告抬头
    "name": "高一物理 期中统测",      // 考试名（文件名、页脚、台账都用它）
    "date": "2026-11",
    "subject": "物理",
    "grade": "高一",
    "full": 100,                    // 卷面满分；不填则用题目分值和
    "org": "",                      // 机构名，留空则不显示
    "campus": "示例校区",
    "teacher": "示例教师"
  },
  "avg_mode": "auto",               // auto=本班算 | manual=用每题 avg
  "grade_mode": "pct",              // pct=得分率线 | quantile=全班分位
  "grades": {"A": 0.90, "B": 0.70, "C": 0.30, "D": 0.10},
  "bands": [[0,0.3],[0.3,0.4],[0.4,0.5],[0.5,0.6],[0.6,0.7],[0.7,0.8],[0.8,1.0]],
  "module_shorts": {"运动的描述": "运动描述", "运动图像": "运动图像"},
  "questions": [
    {
      "no": 1,
      "full": 4,
      "module": "运动的描述",
      "kp": "参考系",                       // 显示名（优先从知识树取）
      "kp_id": "26e5c22ffe",                // 树节点哈希（有它才能跨卷聚合掌握度）
      "kp_src": "manual",                   // manual=老师点的 / ai=预填待确认
      "errors": ["concept", "reading"],     // 题级常见错因（code 见 error-tags.json）
      "book": "P6-13 知识点",
      "advice": "重记物理量定义",                 // 进「回补动作清单」
      "skill": "记忆物理量定义，结合题目理解",     // 进「逐题详评·后续学习建议」
      "avg": 4.00                                 // 仅 avg_mode=manual 时需要
    }
  ]
}
```

| 字段 | 必填 | 说明 |
|---|---|---|
| `exam.name` | ✓ | 一次考试唯一标识 |
| `questions[].no` | ✓ | 题号，字符串或数字都行，脚本统一转字符串 |
| `questions[].full` | ✓ | 该题满分（不是得分！） |
| `questions[].module` | ✓ | 模块名，同一个名字的题会汇总成一行 |
| `questions[].kp` | ✓ | 知识点显示名（点分，别写整段话） |
| `questions[].kp_id` | 建议 | 知识树节点哈希；没锚点的知识点仍会显示，但不参与跨卷掌握度统计 |
| `questions[].errors` | 建议 | 题级常见错因 code（可多个），见 `assets/error-tags.json` |
| `questions[].book` | 建议 | 课本位置，如 `P27-30 例题4`；没有就留空显示「—」 |
| `questions[].advice` | 建议 | 回补动作（怎么写作业），一短语 |
| `questions[].skill` | 建议 | 解题技巧/学习方法，一句话 |
| `bands` | 否 | 成绩段。**上界全 ≤1 时按"占满分比例"解释**（推荐，换满分自动适配）；也可写绝对分 `[[0,60],…]`。低分合并写 `[0,0.3]` |
| `grades` | 否 | 等级阈值，按得分率；默认 `{"A":0.9,"B":0.7,"C":0.3,"D":0.1}`（与机构旧表一致） |
| `module_shorts` | 建议 | 雷达图轴名，4–6 字，不给就自动截断 |
| `brand` | 否 | 机构 Logo 与主题色，由 `scripts/brand.py` 写入（见下节）。没有就用默认蓝 `#3F3B92`、页眉留空 |

## 机构品牌（可选，`brand`）

```json
"brand": {
  "logo": "brand/logo.png",     // 相对考试文件夹；图片由 --logo 复制进来
  "logo_from": "校徽.png",       // 原始文件名，只作记录
  "color": "#C8102E",            // 主题色；报告里的标题/分数/图表/表格线都用它
  "color_source": "auto"         // auto=从 Logo 取色，manual=--theme 指定
}
```

- 只有 `brand.logo` 没有 `brand.color` 时，渲染会现取一次色（花不到 1 秒）；`brand.py` 设值时会把颜色直接算好写进去。
- 删掉 `brand` 字段（`brand.py --clear`）= 去掉 Logo、回默认蓝。
- 模板里所有品牌色都走 CSS 变量 `--accent` 系列，**不要在模板里写死色值**，否则换色会漏掉那一处。

## 建卷归一规则（不同卷面结构 → 同一张表）

真实卷子长什么样都有，按下面的规则压平：

1. **题号口径统一按「计分单位」**：一道大题里 3 个小问合起来 12 分且一起给分 → 记 **1 条**（no=15, full=12，kp 写「…（三问）」）；若小问独立给分 → 各记一条（no=`15(1)`, `15(2)`）并保证分值和 = 卷面分。
2. **选择题按题号逐条**，不要把「1–8 单选共 32 分」合成一条——那样报告里就查不到具体错哪题。
3. **选做题 / 二选一**：按学生实际作答的那部分记，另一部分标 `"optional": true` 并在 `full` 上不计入总分；如果全年级都做同一部分，直接忽略另一部分。
4. **卷面分和对不上**：先怀疑自己读错分值，`Σ题目满分` 必须等于卷面满分。真对不上（如卷面含 5 分卷面分/实验报告分）→ 在 `exam.full` 填真实满分，并单独加一条 `{"no": "卷面", "full": 5, ...}` 或直接告诉老师这个差额，让他确认。
5. **照片/扫描件糊**：拿不准的分值**不要猜**，在交付时列成「第 X 题分值看不清，请确认」的清单。猜错的代价是全班报告全错。
6. **带解析/答案的卷子**：解析文字用来写 `advice` / `skill`（这是最好的素材），但**不要**把解析原文整段塞进去，压成一句可执行的建议。
7. **模块划分**：优先用教材章-节口径（组卷网/菁优网那样），一个模块 10–50 分比较合适；只有 4 分的小节不要单独成模块，并到上一级。

## 建卷自检（写完后必跑）

```bash
python -c "import json;d=json.load(open('paper.json',encoding='utf-8'));print('题数',len(d['questions']),'分值和',sum(float(q['full']) for q in d['questions']),'卷面满分',d['exam'].get('full'))"
```

对不上就别往下走。

## 话术（可选，`comments` 字段）

两种写法都支持，按分数段更贴近老师习惯（与旧 Excel 的「起始分/结束分」一致）：

```json
// ① 按分数段（推荐）
"comments": [
  {"from": 0,  "to": 50,  "text": "这次考试有点失手了哦，不过高一才刚刚开始…"},
  {"from": 50, "to": 80,  "text": "这次考试成绩还不错，但还需要继续努力…"},
  {"from": 80, "to": 100, "text": "这次考试很棒！但不要骄傲哦…"}
]

// ② 按等级
"comments": {
  "A": "这次{grade}等，总分 {total}/{full}，{strong}；把{weak}的错因整理一下，保持节奏。",
  "C": "这次{grade}等，总分 {total}/{full}。{strong}；{weak}是主要失分点。"
}
```

可用占位符：`{name} {grade} {total} {full} {strong} {weak} {lost_q}`（不认识的占位符原样保留，可直接贴纯文本话术）。

**优先级**：`panels.json`（逐人点评，v0.6 起的正式来源）> `comments.json`（老师逐人写的话）
> `paper.json.comments`（按等级或分数段的话术）> 内置兜底句。

## v0.6 新增字段（Excel 收表自动写入）

主入口是 `ingest_excel.py`（读老师填的两 Sheet 模板），下面字段由它写入，旧数据缺省即为空：

| 字段 | 来源 | 说明 |
|---|---|---|
| `exam.title_given` | 试卷信息「考试名称」 | 老师填的试卷名称；**可为空**，空则报告页眉不显示这一项。`title` 字段仍是自动拼的「年级科目 试卷分析报告」，供明细页与文档标题兜底 |
| `exam.note` | 试卷信息「考试备注」 | 本次考试范围、教学进度、作答安排等公共背景；只作写作证据 |
| `exam.class` | 试卷信息「班级」 | 报告抬头「班级」列 |
| `exam.paper_file` | `--paper` 归档结果 | 形如 `01_试卷/xxx.pdf`；为空表示本次没有原卷，点评不得引用题干 |
| `questions[].type` | 试卷信息「题型」 | 选择题/填空题/作图题/实验探究题/解答题/计算题 |
| `questions[].note` | 试卷信息「题目备注」 | 命题意图、评分要点、讲授情况；与 `errors_note`（具体错因）不是一回事，两者不合并 |
| `students[].note` | 学生成绩「学生备注」 | 只进该生自己的点评，不得带入其他学生 |

`exam.full` 由收表按 Σ题目分值写入；老师若在模板里填了「卷面满分」且与合计不符，收表会直接报错，
不会静默取其一（真实卷出现过页眉印 100、逐题合计 84 的情况）。
